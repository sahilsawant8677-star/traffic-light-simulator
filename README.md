## 📖 About the Project

The **Traffic Light Simulator** is a simple web-based project that demonstrates the working of a traffic signal.

It displays different traffic light states such as:

* 🔴 **Red** – Stop
* 🟡 **Yellow** – Wait / Get Ready
* 🟢 **Green** – Go

The project was created to understand the basics of **HTML and web page development** while building a simple real-world simulation.

## ✨ Features

* 🚦 Simple traffic light interface
* 🔴 Red, 🟡 Yellow and 🟢 Green signals
* 🌐 Runs directly in a web browser
* 💻 Simple and beginner-friendly design
* 🎓 Developed as a Semester 3 college project

## 🛠️ Technology Used

**HTML (HyperText Markup Language)**

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Find the main `.html` file.
4. Double-click the HTML file.
5. The Traffic Light Simulator will open in your web browser.
